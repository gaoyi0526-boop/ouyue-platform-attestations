# Ouyue Platform Attestations

This public repository is an isolated GitHub Actions OIDC attestation provider
for frozen governance manifests consumed by the private `ouyue-skills`
repository.

Only the following content may be published here:

- the pinned attestation workflow;
- strict pre-sign validation code;
- frozen, sanitized governance manifests and their checksums.

The repository must not contain business data, knowledge-base content, browser
state, credentials, OIDC tokens, private keys, raw trusted roots, downloaded
attestation bundles, SQLite replay state, or unrelated Git history.
